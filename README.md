# election-2026

台灣歷屆選舉 **鄉鎮市區（行政區）層級** 得票資料庫，供 2026 地方選舉民調追蹤（`poll-tracker.html`）與選情分析使用。

所有資料檔皆為純 JavaScript 變數宣告，可直接以 `<script>` 載入，或於 Node／Python 中解析。全國 22 縣市、368 行政區，**各檔的 `縣市代碼／行政區名稱` 鍵值完全一致，可直接互相 join**。

## 二、共同結構

```js
var DIST2020 = {
  TPE: {                       // 縣市代碼（見第三節）
    county: "臺北市",
    cands: ["宋楚瑜", "韓國瑜", "蔡英文"],   // c[] 的固定順序
    districts: [
      { d: "松山區", c: [ {name: "宋楚瑜", votes: 5436, rate: 4.33}, ... ] },
      ...
    ]
  },
  ...
};
```

- `cands`：該縣市 `c[]` 的項目順序，全縣市一致。
- `districts[].d`：行政區名稱，一律採**現行**名稱（例如「板橋區」）。
- `c[]`：`{name, votes, rate}`，`rate` 為佔有效票百分比，四捨五入至小數第 2 位，合計 100%。

### 候選人型（`district-*`、`village-*`）

- `c[]` 為**全部候選人**，未套用任何顯示門檻。
- `parties`（2014、2016、2018、2022 有）：候選人 → 推薦政黨對照。2020、2024 總統檔尚無此欄。
- `hasVil`（2014、2018、2022 有）：該縣市在對應的 `village-*.js` 有無村里資料。

### 村里檔（`village-*`）

結構不同，為 `{ 縣市代碼: [ {d: 行政區, v: 村里, c: [...]} ] }`，需要時才另行載入（每檔約 1.7 MB）。

### 政黨型（`partylist-*`、`legislator-*`、`councilor-*`）

- `cands`：主要政黨清單，最後一項為「其他」（立委、議員另有「無黨籍」）。
- `c[]`：主要政黨＋其他，合計 100%。主要政黨即使得票為 0 也會列出。
- `all[]`：全部政黨完整明細，依得票數排序。
- `valid`：有效票數。
- 立委、議員為**依候選人推薦政黨加總重建**的政黨得票，非選票上的政黨票。

| 年份 | 不分區主要政黨 |
|---|---|
| 2016 | 國民黨、民進黨、時代力量、親民黨、新黨 |
| 2020 | 國民黨、民進黨、民眾黨、時代力量、台灣基進、親民黨 |
| 2024 | 國民黨、民進黨、民眾黨、時代力量、台灣基進 |

議員主要政黨：2014 為國民黨、民進黨、親民黨、台聯、無黨籍；2018 為國民黨、民進黨、時代力量、親民黨、無黨籍；2022 為國民黨、民進黨、民眾黨、時代力量、台灣基進、無黨籍。

### 額外欄位

| 欄位 | 所在檔案 | 說明 |
|---|---|---|
| `split` | `legislator-*` | 該行政區橫跨的立委選舉區數 |
| `areas` | `legislator-*` | 所屬選舉區清單；單一選區縣市寫「選舉區」 |
| `indep` | `councilor-*` | 無黨籍得票率（%），資料品質旗標 |

## 四、驗證方式

每個檔案產出時都通過以下檢查：

1. 行政區內各候選人／政黨票加總 = 該行政區有效票。
2. 行政區加總 = 原始檔縣市總計列，且與中選會公告的縣市有效票相符。
3. 全國合計得票率與中選會公告一致。
4. 行政區名稱與其他年份檔案逐一比對，零差異。

2016 總統與區域立委另以兩份獨立取得的中選會原始檔各自計算，368 區結果完全一致。

## 五、使用注意事項

- **不同選舉類型測的東西不同。** 總統、縣市長、區域立委反映候選人強度；不分區政黨票最接近政黨基本盤。各類型之間的差距是本質性的，不是資料錯誤，不宜混用作同一條基準線。
- **議員為複數選區（SNTV）。** 政黨總票受提名人數影響。無黨籍比例高的行政區（見 `indep`），藍綠差距代表性很弱。
- **立委選區重劃。** 2016 的 `split > 1` 行政區（高雄三民、前鎮，臺中大里等）與 2020／2024 不同（高雄苓雅、新竹縣竹北、臺南東區）。跨 2016→2020 比較時，這幾區的變動可能來自選區重劃。2020 與 2024 的 `split > 1` 為完全相同的 12 區。
- **新竹市議員。** 東區、北區各含 2 個議員選舉區（以里劃分），已合併計入行政區。
- **2018 臺中市議員。** 第 7 選區曾經司法重新計票，本檔採中選會原始候選人得票，與部分彙總來源差 252 票。
- **原住民選舉。** 立委與議員檔皆**不含**平地／山地原住民選區，以免與一般選區重複計票。
- **年份範圍。** 收錄年份皆在 2010 年縣市合併之後，各檔行政區鍵值已與現行行政區對齊，可直接跨年比較；2010 年以前的資料未收錄。
- **2014 行政區改名。** 苗栗縣頭份鎮、彰化縣員林鎮於 2015 年改制為市，2014 各檔採現行名稱（頭份市、員林市）。村里檔的村里名稱則為各年當時名稱，跨年比對村里時需注意村里整併與改名。
- **Big5 缺字。** 中選會原始檔以私用區碼點存放 Big5 缺字（如磘、廍、𥕢、塭、欍），各檔皆已還原為正確字；對照表見 `parse.py`。

## 六、資料來源與授權

選舉資料來自 **中央選舉委員會「選舉資料庫」**，依 [政府資料開放授權條款第 1 版](https://data.gov.tw/license) 利用。

- 2018–2024 各檔：中選會公告之得票數一覽表（xls／xlsx）。
- 2014 縣市長與議員：中選會原始檔，經 MISNUK/CECDataSet 取得，並以 kiang/db.cec.gov.tw 保存之同一原始檔交叉驗證（新北、高雄縣市長最初取自中選會公告之候選人得票數一覽表，與原始檔逐筆相同）。
- 2016 總統、區域立委：中選會原始檔（elbase／elcand／elctks／elprof），經 [MISNUK/CECDataSet](https://github.com/MISNUK/CECDataSet) 取得，並以 [kiang/db.cec.gov.tw](https://github.com/kiang/db.cec.gov.tw) 保存之同一原始檔交叉驗證。
- 2016 不分區政黨票：中選會原始檔，經 kiang/db.cec.gov.tw（Taiwan Election Results Database by Finjon Kiang，CC BY 4.0）取得。

本資料庫僅保留候選人姓名與得票，未收錄候選人出生日期、學歷等個人資料。
